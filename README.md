<h1>Projeto NETFLIX</h1>
<br>
Página básica inspirada na Netflix, utilizando HTML, CSS e JavaScript. O projeto começou com a estrutura em HTML,
onde organizei os elementos principais, como o cabeçalho, as seções de filmes e séries, e os botões de navegação.
Para dar vida à interface, utilizei CSS, aplicando estilos que refletem a estética da plataforma, como cores escuras e tipografia marcante. 
Também adicionei efeitos de hover e transições suaves para tornar a experiência do usuário mais agradável.
A parte mais desafiadora foi implementar JavaScript para criar interatividade. Adicionei funcionalidades como um carrossel de imagens entre as produções.
Esse projeto não só me desafiou a aplicar conhecimentos técnicos, mas também a entender a importância do design na experiência do usuário.
